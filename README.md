# cnvrt_Ytb_to_mp3
Convert a Youtube video to an audio file.

This program uses a CLI style UI. 
To install the dependencies first run ```pip install -r requirments.txt```
Next enter into the terminal and run it using ```python3 convert.py```
The program has three options: view logs, download video, and exit the program.

The program prompts the user for the input that is required mainly the url,
the file format to save to, whether to download as a playlist, and the file
path to save to. The filenames should have dashes between
them like this: ```path/to/file/name```
