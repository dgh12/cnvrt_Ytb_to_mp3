# cnvrt_Ytb_to_mp3
Convert a Youtube video to an audio file.

This program uses a CLI style UI. 
To run first install python and the libraries "deno", and "yt_dlp"
Next enter into the terminal and run it using "python3 convert.py"
The program has three options: view logs (requiring entering the password "password"), download video, and exit the program.

The password can be changed by changing the value of the all caps PASSWORD variable in the convert.py file to change the password.

The download video option requires three user inputs, the video url, the file type to save to and the folder to save the video to.
The input folders begin after the home folder and forward slashes "/" are used to separate folders.
